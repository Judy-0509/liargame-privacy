# 5천만 분의 1

한국의 공표 통계로 만든 인생 시뮬레이션 웹게임입니다. [1 in 8 Billion](https://1in8b.life)의 구조(무작위 출생 → 실시간으로 흐르는 한 생애 → 사망 기록과 추모)를 한국인 대상으로 다시 설계했습니다. 141개국 대신 17개 시도, 세계 인구 80억 대신 한국의 출생아 중 하나로 태어납니다.

- 나라·지역·부모를 고를 수 없고, 태어나는 해(1960~2060)와 세상(지난·지금·다가올)만 고릅니다.
- 체력·멘탈·스펙·인맥 네 스탯과 돈(자산·소득·빚·주거)이 생애 전체에 걸쳐 변합니다. 인맥은 취업·이직 확률에, 체력은 번아웃에, 스펙은 입시·취업에, 멘탈은 결정과 건강에 영향을 줍니다. 상단 픽셀 장면이 지금 상태(계절, 집, 복장, 표정, 가족, 반려동물, 차, 재산)를 계속 보여 줍니다.
- 고교 선택, 수능, 학비, 병역, 취업, 이직, 번아웃, 결혼, 신혼집, 출산, 육아휴직, 집 마련, 투자, 암 치료, 금연, 퇴직 후 진로, 부모 돌봄, 자녀 결혼, 노인 일자리, 요양 등 25가지 결정이 통계적 확률과 함께 제시됩니다.
- IMF, 금융위기, 코로나19 같은 실제 사건이 해당 연도에 기록에 남고 경제에 영향을 줍니다. 다가올 세상은 통계청 장래인구추계(중위)를 가정으로 씁니다.
- 생존 곡선, 인생 지도(한 칸 = 1년), 같은 날 태어난 네 아이의 삶, 전생 기록(최근 10개), 추모관(촛불·한마디), 공유 카드(PNG)를 제공합니다.
- 재산 구성(현금·예금·주식·코인·전세 보증금·집 시세·자동차에서 빚과 대출을 뺀 순자산)과 보유한 것(집, 차, 반려동물, 스마트폰, 노트북, 운전면허 등)을 따로 보여 줍니다.
- 스크롤 없이 한 화면에서 진행됩니다. 휴대폰에서는 기록·재산·지도·생존·같은 날 탭으로, 넓은 화면에서는 세 열로 나뉩니다.
- 대입은 수능 백분위와 내신 등급을 바탕으로 수시 6장 + 정시 3장을 씁니다. 상향·적정·안정 프리셋 셋 중 고르거나 직접 대학(13개 묶음 분류)과 장수를 정하고, 7대 계열을 고른 뒤 2학년에 중계열을 정합니다. 통계는 인구 비율이 아니라 "내가 한 행동의 결과 확률"로만 쓰며, 쉬었음·흡연·음주·학원도 내가 고르는 결정입니다(`js/admission.js`).
- 대학에 들어가면 매년 "올해는 무엇을 할까"를 고릅니다. 동아리·학생회·과외·알바·방학 인턴·학부연구생(조교)·대외활동·봉사·공모전·창업동아리·토익·복수전공·교환학생·어학연수·연애·학점·놀기·여행·휴학(입대·알바·워킹홀리데이·여행·시험·창업·쉬기)·편입·반수 중 하나이고, 인턴 정규직 전환이나 교수 추천 취업 같은 후속 사건으로 이어집니다.
- 30세 이전 구간에 돌잡이, 영어유치원, 영재원, 경시대회, 조기유학, 영재고·과학고·외고·자사고·예고, 문·이과, 모의고사, 수시, 의·치·한·약대, 최상위권 대학, 전공, 학점, 동아리·CC, 어학연수, 인턴·토익, 배낭여행, 청약통장, 로스쿨·임용고시 등 60여 개 사건과 10개 결정이 있습니다(`js/youth.js`).
- 오늘의 순위: 서버(`server/`)를 띄우면 그날 플레이한 모든 사람 중 순위가 사망 화면과 홈에 표시됩니다. 닉네임 선택 입력.
- 순위: 삶이 끝나면 같은 해에 태어난 500명을 자동 진행으로 살게 해 인생 점수·최종 재산·수명·행복·생애 소득·관계에서 몇 위인지 보여 줍니다. 인생 점수는 수명·행복·관계·재산 백분위의 평균입니다. 홈의 순위표에서는 이 기기에 남은 삶(최근 30개)끼리 겨룹니다. 전체 플레이어 순위는 서버가 있어야 가능합니다.
- 서버 없음. 모든 기록은 브라우저 localStorage에만 저장됩니다. 자살은 다루지 않습니다. 15세 이상 권장.

## 오늘의 순위 (서버)

`server/server.js`는 의존성 없는 Node 서버입니다. 맥미니에서 `node server/server.js`로 띄우고 `js/config.js`의 `apiBase`에 주소를 넣으면, 삶이 끝날 때 기록이 올라가고 그날 플레이한 모든 사람 중 순위(인생 점수·재산·수명·행복·생애 소득·관계)가 사망 화면과 홈의 "오늘의 순위"에 나옵니다. 닉네임은 홈에서 선택 입력합니다. 실행·터널·API는 `server/README.md`를 보세요.

## 생애 단계별 사용 통계

게임 안 "한국 통계" 화면에 출생·영유아, 초등, 중학, 고교, 대학, 병역, 취업·일, 사랑·결혼·출산, 주거·돈, 중년·건강, 노년, 사망의 13단계로 실제 계산에 쓰는 값 150여 개와 출처를 모두 적어 두었습니다(`js/data.js`의 `stageStats`).

## 실행

빌드 과정이 없는 정적 사이트입니다.

```bash
python3 -m http.server 8765   # 그 다음 http://localhost:8765 접속
```

GitHub Pages: 저장소 Settings → Pages → Branch를 이 브랜치(또는 main)의 `/ (root)`로 지정하면 바로 배포됩니다. `manifest.webmanifest`와 `sw.js`가 있어 홈 화면 추가와 오프라인 실행이 됩니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 세 개(홈·생애·사망 기록)와 모달 껍데기 |
| `styles.css` | 다크/라이트 테마, 모바일 우선 레이아웃 |
| `js/data.js` | 통계 입력값. 연도별 테이블(출생아, 출산율, 기대수명, 영아사망률, 대학 진학률, 초혼 연령, 복무 기간, 흡연율, 실질소득·집값 지수 …), 지역, 소득 분위, 사망 원인, 암종, 직업군, 이름, 역사 사건, 출처 |
| `js/sim.js` | 엔진. 난수, 생명표(Gompertz–Makeham를 연도별 기대수명에 맞춤), 출생, 연 단위 진행(가족→교육→병역→일→사랑·자녀→주거→건강→돈→스탯→사망), 요약 |
| `js/decisions.js` | 결정 정의. 각 결정은 `when`(발생 조건), `valid`, `options`(라벨·힌트·자동 선택 가중치·효과)로만 이루어짐 |
| `js/ui.js` | 렌더링(상단바, 스탯, 기록, 인생 지도, 생존 곡선, 같은 날 아이들, 가족·돈·통계 모달, 공유 카드) |
| `js/app.js` | 흐름 제어. 타이머·배속·일시정지, 결정/생각 멈춤 모달, 저장·이어하기, 전생·추모관, 음악, 테마, 설치 |
| `tools/simtest.js` | 자동 결정으로 수천 명을 살게 한 뒤 분포를 출력하는 보정 도구 |

엔진은 DOM에 의존하지 않으므로 Node에서 바로 돌릴 수 있습니다.

```bash
node tools/simtest.js 2000 2026        # 2026년생 2,000명
node tools/simtest.js 1500 1975 show   # 1975년생 + 한 명의 전체 기록 출력
```

## 모형 메모

- 사망률: 성별·연도별 기대수명(통계청 생명표, 장래추계)에 맞춘 Gompertz–Makeham 위험률에 건강 스탯, 소득 분위, 흡연·음주, 치매, 노인 빈곤 보정을 곱합니다. 암은 발생률과 암종별 5년 생존율을 따로 두고 치료 선택에 따라 달라집니다.
- 돈: 모든 금액은 2024년 원화 가치 기준입니다. 지난 세상의 소득·집값은 1인당 실질소득 지수와 실질 주택가격 지수로 환산했습니다. 주거는 소득·자산으로 감당 가능한 범위 안에서 지역 평균 이하 집을 고르는 것으로 가정합니다.
- 결정의 자동 선택 가중치는 해당 코호트의 실제 비율(대학 진학률, 생애 결혼 확률, 기혼 가구 자녀 수 분포 등)에 근사하도록 `tools/simtest.js`로 맞췄습니다.
