# 5천만 분의 1 — UI 기획 (v1.0 턴제 개편)

## 원칙
1. 한 화면. 어떤 화면도 세로 스크롤이 생기지 않는다. 길어지는 것은 패널 안에서만 스크롤한다.
2. 한 손. 휴대폰 세로에서 엄지 하나로 진행된다. 주요 버튼은 화면 아래에 둔다.
3. 한 눈. 지금 몇 살이고, 무엇을 하고 있고, 다음에 무엇을 고르는지가 3초 안에 읽힌다.
4. 확률은 숨기지 않는다. 선택지마다 확률과 대가를 적고, 선택 뒤에는 무엇이 얼마나 바뀌었는지 적는다.

## 화면 구성

### 1. 홈
```
┌──────────────────────────────┐
│ 한국에서 무작위로 태어나는 인생 시뮬레이션 │
│          5천만 분의 1          │
│ 오늘 한국에서는 654명이 태어납니다 … │
├──────────────────────────────┤
│ [ 오늘의 아기로 태어나기 ]  ← 모두 같은 아이, 당일 순위 │
│ [ 무작위로 태어나기 ]                                 │
│   세상: 지난 | 지금 | 다가올    해: ──●──── 1990         │
│ ▸ 친구가 보낸 시드로 태어나기                          │
│ 닉네임 (선택)                        [이어하기]        │
├──────────────────────────────┤
│ 전생 기록 · 추모관 · 순위표 · 오늘의 순위 · 도전과제 · 한국 통계 · 이용 안내 │
└──────────────────────────────┘
```
- 오늘의 아기: 날짜로 만든 시드. 전 세계 모든 플레이어가 같은 출생 조건에서 시작하므로 오늘의 순위가 공정하다.
- 시드: 사망 화면의 "같은 아이로 다시" 링크(`?seed=…&y=…`)로 친구와 같은 아이를 다른 선택으로 살아 볼 수 있다.

### 2. 생애 화면 (턴제)
```
┌──────────────────────────────┐
│ 김이준 남·경기·초등학생        8세 2034년 │  ← 이름줄 + 나이
│ ┌──────── 픽셀 장면 ────────┐ │  ← 계절·집·인물·가족·차·재산
│ └──────────────────────────┘ │
│ ▮▮▮▮▮▮▮▮▮▮▮▮  2034년 3월     │  ← 한 해 진행 막대 (턴 애니메이션)
│ 체력 ▮▮▮▮ 79  멘탈 ▮▮▮ 50     │
│ 스펙 ▮▮ 41    인맥 ▮▮▮ 55     │
│ 순자산 0원 · 주거 부모 집      │
│ 초점 [균형▾]  ☐ 자동 결정   유년기 1/7 │
│ [연표] 재산·보유  지도  생존  같은 날 │  ← 탭 (휴대폰), PC는 세 열
│ ┌──────────────────────────┐ │
│ │ ▾ 유년기 (0~12세) 요약: 세종, 6분위, 학원 │ │
│ │  ✨ 8세 첫 자전거가 생겼다          ☆ │ │
│ │  🎓 6세 초등학교에 입학했다          ☆ │ │
│ │  …                                   │ │
│ └──────────────────────────┘ │
│ [ 다음 해 ▶ ]  [ 다음 갈림길 ▶▶ ]   ⋯ │  ← 하단 고정 턴 바
└──────────────────────────────┘
```
- 다음 해: 한 해를 진행한다. 결정이 있으면 먼저 묻고, 그 해의 사건을 연표에 올린 뒤 진행 막대가 0→12월로 차오른다(0.7초).
- 다음 갈림길: 결정·챕터 성적표·죽음이 나올 때까지 조용한 해를 자동으로 넘긴다.
- 자동 결정: 켜면 갈림길에서 통계적으로 흔한 쪽을 고른다. 메뉴의 "자동 재생"(또는 P)을 켜면 3초마다 한 해가 흐른다(구경 모드). 결정과 성적표에서는 멈춘다.
- 연표: 10년 단위로 접히는 묶음. 최신 묶음만 펼쳐지고, 묶음 머리에 그 시기의 요약 한 줄이 붙는다. 아이콘으로 종류를 구분하고(🎓💼❤️🍼🏠💊⚠️🎖️💰🛍️📰👪✨✍️🎲), 전체 펼치기 토글이 있다.
- 키보드: Space/Enter = 다음 해, N = 다음 갈림길, P = 자동 재생.

### 3. 갈림길 카드
```
┌──────────────────────────────┐
│ 결정 · 17세 · 2043년           │
│ 원서를 쓴다                     │
│ 예상 수능 백분위 66 (상위 34%), 내신 4등급. 수시 6장 + 정시 3장. │
│ 친구 하은: "나는 상향으로 간다"   │  ← 인물 한마디 (있을 때)
│ ┌ 상향 지원 (공학 계열) ───────┐ │
│ │ 최상위 2·서울 상위 2… · 한 곳 이상 합격 46% │ │
│ ├ 적정 지원 … 합격 96% ───────┤ │
│ ├ 안정 지원 … ───────────────┤ │
│ ├ 직접 고르기 ───────────────┤ │
│ └ 수능 없이 취업 ─────────────┘ │
│ (이번엔 자동으로)               │
└──────────────────────────────┘
```
- 선택지 제목 + 힌트(확률·비용·대가). 선택 뒤 연표에 "🎲 예상 수능 백분위: 61% → 68%"처럼 변화가 남는다.
- 직접 고르기는 전용 화면(계열, 프리셋, 대학별 수시·정시 합격률과 장수).

### 4. 챕터 성적표 (12·19·29·39·49·59·69세)
```
┌──────────────────────────────┐
│ 20대 끝 · 29세                 │
│ 이 10년: 수도권 중위 대학 졸업 · 중소기업 · 연애 2번 │
│ 출발선 대비 (소득 4~7분위 가정 134명 중)             │
│  스펙 상위 35%  인맥 83%  체력 42%  멘탈 78%  재산 72% → 62점 │
│ 바뀐 확률: 대기업 합격 가산 0% → 8% · 사망 위험 1.0 → 0.85 │
│ 한마디: 친구 하은 "공무원이 답이야" / 어머니 "만나는 사람은 있니?" │
│ 생각 한 줄 [                    ]                  │
│ [ 계속 ]                                            │
└──────────────────────────────┘
```
- 이전의 "생각 멈춤"을 대체한다. 같은 형편에서 태어난 500명과 같은 나이의 스냅샷을 비교한다.

### 5. 사망 기록
```
┌──────────────────────────────┐
│ 사망 기록                      │
│ 최선우, 1988–2048               │
│ 1988년 경남에서 태어나 … 60세에 간암으로 세상을 떠났다 │
│ 학력·주된 일·결혼·자녀·주거·재산·생애 소득·스탯 (2열)     │
│ ★ 출발선 대비: 소득 1~3분위 가정 150명 중 12위 (상위 8%) │
│ 같은 해 500명 중: 인생 점수·재산·수명·멘탈·소득·인맥 순위 │
│ 오늘 플레이한 37명 중 4위  [오늘의 순위 보기]           │
│ 도전과제: 수저 역전 · 반려 가족 · 평생 금연              │
│ 남긴 것: 🏠 경남 집 · 🚗 준중형차 · 🐾 콩이              │
│ [공유 카드] [자녀로 이어하기] [같은 아이로 다시] [추모관] [기록] [다시 태어나기] │
└──────────────────────────────┘
```
- 자녀로 이어하기: 살아 있는 자녀 중 하나를 골라 그 아이로 태어난다. 지역·형편·상속이 이어지고 "2대째"가 표시된다.
- 같은 아이로 다시: 시드 링크를 복사한다.

### 6. 순위와 도전과제
- 순위표(기기): 지표 선택(인생 점수·출발선 대비·재산·수명·멘탈·소득·인맥).
- 오늘의 순위(서버): 날짜·지표 선택, "오늘의 아기만" 필터, 내 기록 강조.
- 도전과제: 16개 배지. 달성한 것은 색, 미달성은 회색과 조건 설명.

## 상태 색과 아이콘
- 연표 종류별 아이콘은 위와 같다. 경고(⚠️)와 확률 변화(🎲)는 노란 글씨, 역사 사건은 파란 글씨, 죽음은 빨간 글씨.
- 스탯 막대 색: 체력 초록, 멘탈 노랑, 스펙 파랑, 인맥 분홍. 순자산이 음수면 빨간 글씨.

## 반응형
- 900px 미만: 세로 한 열, 탭으로 패널 전환, 하단 턴 바 고정.
- 900px 이상: 상단에 픽셀 장면·이름·나이, 세 열(재산·지도 | 연표 | 생존·같은 날), 하단 턴 바.
